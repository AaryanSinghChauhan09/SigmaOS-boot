# SigmaOS-boot

> **SigmaOS Boot Subsystem** — Boot configuration, multiboot/Limine protocol handling, and live image hooks.

Part of the [SigmaOS](https://github.com/AaryanSinghChauhan09/SigmaOS) ecosystem.

## Quickstart

```bash
cargo build --release
cargo test
```
